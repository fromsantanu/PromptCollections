## Prompt: Generate a PHP MVC Skeleton (Views-Only) with Home, AI-Doctor, Feedback, and Admin

**Role:** You are an expert PHP engineer. Create a minimal, production-ready **MVC** web app in **vanilla PHP** (no full frameworks). Use **PHP ≥ 8.1**, PSR-4 autoloading via Composer, a single front controller, and clean URLs.
**Critical:** This iteration is **views + routing + controllers only**. **No database**, **no models**, **no persistence**. Pages will later call external APIs for data.

### Functional Scope (v1)

* **Home** (`/`): shows two primary options:

  1. **Meet the AI-Doctor** → `/doctor`
  2. **Provide Feedback** → `/feedback`
* **AI-Doctor (demo)** (`/doctor`):

  * Simple form inputs: name, age, sex, chief complaint, submit.
  * On submit (POST `/doctor/preview`), render a **preview** page with submitted values and a **placeholder** where future API results will be shown.
* **Feedback (demo)** (`/feedback`):

  * Form inputs: name (optional), email (optional), rating (1–5), comments (required).
  * On submit (POST `/feedback/preview`), render a **thank-you/preview** page with submitted values and a **placeholder** for the future “POST feedback API” call result.
* **Admin (protected)** (`/admin`):

  * Access controlled via fixed credentials stored in **.env** (e.g., `ADMIN_USER=admin`, `ADMIN_PASS=secret123`).
  * On successful login, show **Admin Dashboard** with:

    * A **date selector** defaulted to **today**.
    * A **button** “Run Sentiment for Today”.
    * **Placeholders** for:

      * Summary KPIs (e.g., Positive %, Neutral %, Negative %, Total).
      * Chart areas (bar/pie/line) to render after API calls.
      * A table area for “top feedback snippets”.
    * A **“Generate Report JSON”** button that (later) calls an API and then shows a downloadable JSON blob/URL.
  * **Logout** route clears session.

2. **Routing**

* Use a small `Router` (METHOD + PATH → controller@action).
* Define routes in `config/routes.php`:

  * `GET /` → `HomeController@index`
  * `GET /doctor` → `DoctorController@index`
  * `POST /doctor/preview` → `DoctorController@preview`
  * `GET /feedback` → `FeedbackController@create`
  * `POST /feedback/preview` → `FeedbackController@preview`
  * `GET /admin/login` → `AuthController@loginForm`
  * `POST /admin/login` → `AuthController@login`
  * `POST /admin/logout` → `AuthController@logout` (CSRF protected)
  * `GET /admin` → `AdminController@dashboard` (**protected**)
  * `POST /admin/run-sentiment` → `AdminController@runSentiment` (**protected**, CSRF; returns a **mock JSON** structure for now)
  * `POST /admin/report-json` → `AdminController@reportJson` (**protected**, CSRF; returns a **mock JSON** structure for now)

3. **Auth (Fixed Credentials)**

* No DB. Authenticate by comparing POSTed username/password with `.env` (`ADMIN_USER`, `ADMIN_PASS`).
* On success: set `$_SESSION['admin']=true`.
* `AuthMiddleware` should guard **/admin**, **/admin/run-sentiment**, **/admin/report-json**.
* Show friendly error or redirect to `/admin/login` if unauthorized.

4. **Views & Layout**

* `views/layouts/main.php` contains `<head>`, a simple responsive layout, and includes `partials/navbar.php` with links:

  * Home, AI-Doctor, Feedback, Admin (login/logout logic-aware)
* `partials/flash.php` shows success/error notices from session.
* `home/index.php`: two big cards/buttons linking to `/doctor` and `/feedback`.
* `doctor/index.php`: form with CSRF token; client hints for future API call area.
* `doctor/preview.php`: echo sanitized inputs + a `<div id="aiResult">[API result placeholder]</div>`.
* `feedback/form.php`: form with CSRF token; rating select 1–5; accessibility labels.
* `feedback/preview.php`: echo sanitized inputs + a `<div id="postResult">[API result placeholder]</div>`.
* `admin/login.php`: minimal login form with CSRF.
* `admin/dashboard.php`:

  * date picker default to today
  * buttons: “Run Sentiment for Today”, “Generate Report JSON”
  * section: `partials/kpis.php` (placeholders: Positive/Neutral/Negative/Total)
  * `<canvas id="sentimentChart"></canvas>` and `<div id="tableArea"></div>` as placeholders (no chart lib yet)
  * all results initially mocked; later replaced by API responses.

5. **Security & Utilities (No DB)**

* `Services/Csrf.php`: generate/verify tokens stored in session; helper `csrf_field()` to render hidden input.
* `Middleware/CsrfMiddleware.php`: verify CSRF for all POST routes.
* `Services/Env.php`: load `.env`, `env($key, $default)`.
* Output escaping helper `e()` in `View` or global function file.
* `Session` helper for flash messages.

6. **Front Controller & Rewrite**

* `public/index.php`: start session, load Composer, bootstrap env/config/router, register routes, run middlewares, dispatch, catch exceptions.
* `public/.htaccess`: rewrite all to `index.php`.
* `config/app.php`: app name, base URL, debug flag; read from env:

  ```
  APP_NAME="CareLite MVC Demo"
  APP_ENV=local
  APP_DEBUG=true
  ADMIN_USER=admin
  ADMIN_PASS=secret123
  ```
* Provide `.env.example` with those keys.

7. **Client-Side Hooks for Future APIs (but no real calls now)**

* `public/assets/js/app.js`:

  * Stubs:
