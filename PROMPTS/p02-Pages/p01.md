### 🏗 **System Overview**

Build a **modular FastAPI application** with:

* Database: **MySQL (SQLAlchemy ORM)**
* Auth: **JWT-based login** + **session table** (for refresh tokens)
* Roles: **admin** and **user**
* Features:

  * User registration and login
  * Token refresh and logout
  * Admin panel (via Streamlit) to manage users:

    * list/search users
    * create new users
    * update user details
    * promote/demote users
    * activate/deactivate users
    * delete users
  * Self-service “My Profile” page for users
* Frontend: **Streamlit multipage app** integrated with FastAPI API
* Include optional **workflows/** folder for future agentic logic.

### 🧩 **Implementation Details**

1. **config/settings.py**

   * Use `pydantic_settings.BaseSettings`
   * Include MySQL DSN, JWT secret, algorithm, token TTLs, etc.

2. **db/base.py**

   * Create SQLAlchemy engine + `SessionLocal` + `Base`

3. **models/**

   * `user.py`: `User` model with `id`, `email`, `name`, `password_hash`, `role` (`Enum[admin,user]`), `is_active`
   * `session.py`: `Session` model for refresh tokens (hashed), `expires_at`, `revoked`, `user_id`

4. **schemas/**

   * `auth.py`: Register/Login input + TokenPair output
   * `user.py`: CRUD schemas + admin action (`promote`, `demote`, `activate`, `deactivate`, `delete`)

5. **repositories/**

   * DB access logic for users and sessions (CRUD with SQLAlchemy ORM)

6. **services/**

   * `auth_service.py`: handles registration, password hashing (`bcrypt`), JWT issue, refresh, logout
   * `user_admin_service.py`: handles listing, creating, updating, role change, activation, deletion

7. **controllers/**

   * `auth_controller.py`: `/api/auth` endpoints (register, login, refresh, logout, me)
   * `admin_users_controller.py`: `/api/admin/users` endpoints for admin actions (role/activation)
   * `user_profile_controller.py`: `/api/users/me` for profile retrieval and update
   * Use `require_role(Role.admin)` for admin-only routes

8. **core/**

   * `security.py`: `get_current_user()` using JWT + role guard
   * `deps.py`: DB session + settings dependency
   * `logging.py`: structured logging setup

9. **views/streamlit_app/**
- `Home.py`: landing page (refer Home-Page.png)
- `pages/01_Login.py`: login page (stores tokens in `st.session_state`) (refer Login-Page.png)
- `pages/02_Admin_Users.py` : admin dashboard for user management (refer Admin-Page.png)
- `pages/03_Profile.py`: profile view/update for logged-in user
     - Profile Landing Page (refer User-Profile-Page.png)
     - Profile Edit/Update Page (refer NewOrEdit-User-Page.png)

10. **tests/**

    * `test_auth_flow.py`: register → login → refresh → logout
    * `test_admin_users.py`: admin CRUD & role actions

11. **workflows/**

    * placeholder for LangChain or LLM agent workflows (keep stub files)

12. **Root files**

    * `.env.example`: show example DB URL, JWT_SECRET
    * `pyproject.toml`: include dependencies (fastapi, uvicorn, sqlalchemy, pydantic, bcrypt, mysqlclient/pymysql, streamlit, requests)
    * `README.md`: quickstart guide
    * `Makefile`: commands for run, test, migrate
