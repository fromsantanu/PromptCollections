
The objective : To create a system in php with model-view-controller mechanism 

### Step 1 
Generate the folder sturcture below and create the that are mentioned. Let the .php files be kept empty at this stage.

#### Folder structure
```
Admin-MVC/
│
├── public/
│   ├── .htaccess
│   └── index.php
│
├── app/
│   ├── config/
│   │   └── config.php
│   ├── Controllers/
|   |   └── home_page_controller.php
|   |   └── login_page_controller.php
|   |   └── new_user_page_controller.php
|   |   └── user_page_controller
|   |   └── admin_page_controller
|
│   ├── Models/
│   │   └── session_model.php
|   |   └── user_model.php
|   
│   ├── View/
│   |   ├── partials
|   |   └── home_page_view
│   |   └── login_page_view.php
|   |   └── new_user_page_view.php
|   |   └── user_page_view.php  
│   |   └── admin_page_view.php
|  
├── database.php
└── .env
```
